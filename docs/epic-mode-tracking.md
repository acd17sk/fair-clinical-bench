# Epic Mode tracking

Live log of decisions Epic Mode made while building `fair-clinical-bench`. Each entry is one `epic_run_phase` invocation.

Generated by:

```bash
cat .swarm/evidence/epic-promotions.jsonl | jq -r '"\(.timestamp) phase=\(.phase) → \(.verdict.decision) (p=\(.verdict.p))"'
```

Updated each time a phase runs. See `.swarm/epic/calibration.json` for current calibration knobs and `.swarm/epic/divergence.jsonl` for per-task scope discipline.
